How it works

A complete practice loop

The project joins company-style prompts, a multi-turn interview flow, per-question evaluation, and a final report.

01 / CONFIGURE

Set the context

Choose a company, target role, seniority, interview round, and optional résumé context.

02 / RESPOND

Work through follow-ups

Answer technical questions while the interview state tracks the conversation and its next phase.

03 / REVIEW

See the report

Inspect question-level feedback, an overall breakdown, and a locally saved session history.

Run the full app

Bring your own model, keep control of the session.

The full product is a Next.js application, not a static HTML demo. Its chat, evaluation, and reporting routes call the model selected in Settings. Follow the repository README to run it locally.
