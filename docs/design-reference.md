# 主页设计与素材

主页源码在 `site/`。日常更新见 [editing-guide.md](editing-guide.md)。

- 桌面左栏集中展示魔方头像、姓名、院系和个人账号，右栏依次展示简介、新闻、经历、项目、奖项、论文与学术服务。窄屏把个人栏放到正文上方。
- 姓名、章节标题和简短的小标题使用 [Caveat](../site/assets/fonts/Caveat-OFL.txt) 手写体，个人介绍用 [Comic Neue](../site/assets/fonts/templates/ComicNeue-OFL.txt)，导航和研究内容用 [Outfit](../site/assets/fonts/templates/outfit-OFL.txt)。项目用文字行呈现，经历与获奖使用原有标志，论文保留研究图和分类筛选。
- 新闻按时间倒序放在可滚动的圆角区域中，奖学金、竞赛和论文录用使用对应的表情。色调环由 `site/assets/css/tone.css` 和 `site/assets/js/tone.js` 控制。
- Writing 导航与栏目使用[《ちいかわ》动画官网的乌撒气图片](https://www.anime-chiikawa.jp/images/bg_top_usagi_01.png)。Writing 导航标签和空状态文字也使用 Comic Neue。写作目录水印还使用[动画官网的乘车乌撒气](https://www.anime-chiikawa.jp/images/bg_foot_usagi.png)。

左栏的资料组织参考 [Minimal Light](https://minimal-light-theme.yliu.me/)。新闻和论文的分组参考 [Weidong Tang 的主页](https://wd7ang.github.io/)。论文图、作者与链接的阅读顺序参考 [Richard Zhang](https://richzhang.github.io/) 和 [Phillip Isola](https://web.mit.edu/phillipi/www/) 的主页。早期布局源自 [WowPage](https://github.com/WD7ang/WowPage)，授权见 [MIT 许可证](licenses/wowpage-MIT.txt)。
