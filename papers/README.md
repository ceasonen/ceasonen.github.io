# 论文工作材料

这里保存按会议分类的论文源文件、模板、插图与配套材料。

**如果只是修改个人主页的论文列表，请去 `site/_publications/`，不用在这里找 HTML。**

- 现有 `ijcai/`、`ijcnn/`、`mm/`、`nips/`、`wcl/` 保留原结构，避免破坏 LaTeX 相对路径或既有链接。
- `.bib`、`.bbl`、`.cls`、`.bst` 都可能是编译依赖，不是可随意删除的临时文件。
- 已被 Git 跟踪并推送的文件视为公开材料。在审私有 PDF 只放 `.local/submissions/<会议年份>/`，不放这里，不提交。
- 目录中原本未跟踪的论文工作文件不会由网站构建命令自动提交。

历史归档与临时文件的处理见 [目录说明](../docs/workspace.md)。
