\title{Enabling Visual Reasoning in Text-Only LLMs via Symbolic Scene Descriptions}

\begin{abstract}
We study how far a text-only Large Language Model (LLM) can go on visual question answering when vision is reduced to a compact symbolic interface. Our framework, \textbf{DeepYOLO}, uses an off-the-shelf detector to convert an image into a grammar-constrained scene report of object labels and coarse locations, which is then consumed by a text-only LLM without multimodal pre-training. On a stratified 5k subset of VQAv2, DeepYOLO reaches 42.3\% VQA accuracy, outperforming a scene-graph serialization baseline (38.2\%) while using 2.5$\times$ fewer prompt tokens. Replacing detections with ground-truth objects raises performance to 44.5\%, indicating that detector quality, rather than symbolic reasoning, is the main bottleneck. The resulting pipeline is modular, auditable, and attractive for privacy-sensitive or resource-constrained deployment.
\end{abstract}
